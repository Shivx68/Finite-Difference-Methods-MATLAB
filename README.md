## 📘 Overview

This repository contains MATLAB implementations of various finite difference and computational fluid dynamics (CFD) schemes and problems. The codes serve both as educational examples and as a foundation for deeper exploration in numerical methods for PDEs and CFD.

The repository covers topics such as:

- Linear advection (with analysis of diffusion, dispersion, and stability)  
- Two-dimensional heat conduction (analytical vs numerical comparisons)  
- Quasi-1D compressible nozzle flow  
- Prandtl–Meyer expansion/fan flows  
- Iterative solver stability analyses  
- Other supporting problems (e.g. pendulum ODE, second order ODE)
